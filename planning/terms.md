# Terminology ledger

<!-- SUMMARY: Reader's vocabulary for the RMAL retarget; which specialist terms this venue's readers own (free) and which must be glossed (earned) · status: current · updated: 2026-07-31 -->

Reader assumed: the *Research Methods in Applied Linguistics* readership.
Overwhelmingly second-language acquisition, language teaching, and language
assessment. Validity theory is common ground and is used here as the bridge into
the argument; econometrics is not, and every term borrowed from it is earned.

Built 2026-07-31 during the RMAL retarget, after five simulated reader cold
reads found that "parallel trends" was the single term readers most wanted
defined and that the abstract's closing verdict list read as unglossed jargon.
Both were fixed rather than exempted.

| Term | Status | Reason |
|---|---|---|
| construct underrepresentation | free | Messick's own term; this readership owns validity theory |
| construct-irrelevant variance | free | as above |
| measurement invariance | free | standard in assessment and SEM work; the bridge the paper leans on |
| parallel trends | earned | glossed at first use in §1; removed from the abstract in favour of its definition |
| estimand | earned | glossed at first use in §2 |
| identifying unit / dependence unit | earned | §1 uses plain description, §2 defines both |
| bounded estimate / descriptive reading / shared wave / not identified | earned | all four defined in §6 before use |
| profile | **free** | Not the HPC sense. The single occurrence is journalistic: "a paper that runs more profiles of women in the professions" (§2), meaning a newspaper feature. Flagged by `check-terms.py` because *profile* is on the portfolio-wide watchlist for Brett's kinds work, where it is technical. It is not technical here, and glossing it would imply a theoretical sense the sentence does not carry. |
